DEMO 3 · Pedir dados a uma API (Consola, em jsonplaceholder.typicode.com)
────────────────────────────────────────────────────────
const url = "https://jsonplaceholder.typicode.com/users/1";

const res = await fetch(url);    // pedido GET
const user = await res.json();   // texto JSON → objeto

console.log(user.name);          // "Leanne Graham"
console.log(user);               // o objeto todo

// Depois: separador Network › Fetch/XHR → o mesmo pedido (GET, 200, application/json)

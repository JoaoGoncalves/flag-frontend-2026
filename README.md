## Como obter os materiais

**Sem Git (para já):** botão verde **Code → Download ZIP**.

**Com Git (a partir do módulo 3):**
```bash
git clone https://github.com/JoaoGoncalves/flag-frontend-2026.git
cd flag-frontend-2026
git pull        # no início de cada sessão, para receber o que é novo
```

Os materiais oficiais também ficam no Moodle da FLAG. Dúvidas: fórum da turma ou chat do Teams.

# Exemplos · Parte 17 · Flexbox

Nove páginas pequenas, uma ideia de cada vez, sempre com o mesmo menu de três itens. Escrevemos o CSS juntos, no `<style>` de cada página (o `basic.css` só dá as cores: não mexer).

| Ficheiro | O que vemos |
|---|---|
| `flex1_flex.html` | O contentor: `display: flex` |
| `flex2_axis.html` | O eixo principal: `flex-direction` |
| `flex3_justify.html` | Alinhar no eixo principal: `justify-content` |
| `flex4_margin.html` | Empurrar um item: `margin-left: auto` |
| `flex5_itens.html` | O tamanho dos itens: `flex` e `gap` |
| `flex6_align.html` | Alinhar no eixo cruzado: `align-items` e `align-self` |
| `flex7_wrapping.html` | Quando não cabem: `flex-wrap` |
| `flex8_grow_shrink_basis.html` | `flex`: grow, shrink e basis |
| `flex9_order.html` | Mudar a ordem: `order` |

Exemplos do curso FLAG Fullstack de 2022, revistos.

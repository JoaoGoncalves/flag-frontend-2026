# Exemplos · Parte 18 · Grid

Sete páginas pequenas, uma ideia de cada vez. O exemplo 1 é para ver (o mesmo layout com CSS Grid e com Bootstrap); nos outros escrevemos o CSS juntos, no `<style>` de cada página (o `basic.css` só dá as cores: não mexer).

| Ficheiro | O que vemos |
|---|---|
| `1_example.html` | Para ver: a grelha de 12 colunas com CSS Grid (e com Bootstrap, para comparar) |
| `2_grid_templates.html` | As colunas e as linhas: `grid-template-columns`, `grid-template-rows`, `gap` |
| `3_grid_units_repeat.html` | A unidade `fr` e o `repeat()`; a forma curta `grid-template` |
| `4_positioning.html` | Pôr um item a ocupar várias colunas: `grid-column` e `span` |
| `5_areas.html` | Dar nomes às zonas: `grid-template-areas` e `grid-area` |
| `6_autoFit_minmax.html` | Colunas que se adaptam: `auto-fit` e `minmax()` |
| `7_implicitRow.html` | As linhas que sobram: `grid-auto-rows` |

Exemplos do curso FLAG Fullstack de 2022, revistos.

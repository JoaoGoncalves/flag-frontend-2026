Sobre este site

Este site junta as receitas da família, escritas em HTML durante a formação da FLAG.

Como testamos as receitas

Cada receita é feita pelo menos duas vezes antes de ser publicada. O forno é sempre pré-aquecido, e a farinha é peneirada, nunca despejada.

Quando uma receita leva menos açúcar do que o original, está assinalada a amarelo.

Medidas

Usamos gramas e mililitros: uma chávena tem cerca de 250 ml e o forno vai a 180 °C. Uma forma de 20 cm tem cerca de 314 cm2. A água é H2O, mas o fermento é que faz o bolo crescer.

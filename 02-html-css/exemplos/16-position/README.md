# Exemplo · Parte 16 · Position

O Cabaz da semana (o mesmo das sessões 9 e 10). O `base.css` traz o aspeto; o `position.css` é onde escrevemos, na sessão 12:

1. o selo "Mais pedido" no canto do cartão (`relative` no cartão, `absolute` no selo);
2. o topo sempre visível ao fazer scroll (`sticky`) e o `z-index`;
3. o link "↑ topo" sempre no canto da janela (`fixed`).

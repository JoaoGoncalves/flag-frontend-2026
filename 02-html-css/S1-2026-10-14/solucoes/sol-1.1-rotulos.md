# Solução 1.1 · Marcar um texto à mão

| Linha | Rótulo | Na S2 vai ser |
|---|---|---|
| Bolo de bolacha | título | `<h1>` |
| Uma sobremesa portuguesa… | parágrafo | `<p>` |
| Ingredientes | subtítulo | `<h2>` |
| 200 g de bolacha Maria … 1 chávena de café | lista **sem** ordem (5 itens) | `<ul>` + `<li>` |
| Preparação | subtítulo | `<h2>` |
| Bater a manteiga … Guardar no frigorífico | lista **com** ordem (5 passos) | `<ol>` + `<li>` |
| Mais doces portugueses na Wikipédia | ligação | `<a href="…">` |

A ideia: o HTML não diz como fica bonito, diz **o que cada coisa é**. A ordem dos passos importa, a dos ingredientes não: é por isso que há dois tipos de lista.

# Exercício 11.1 · A folha de estilos em todo o site

> Parte 11 · Introdução ao CSS · sessão 7 (5 min)

No stop ligámos o `css/estilos.css` ao `index.html` e ao `receitas/posset-de-limao.html`. Faltam as outras páginas de `s07/site/`:

1. **`sobre.html`**: está na raiz, como o index.
2. **`receitas/bolo-de-bolacha.html`**: um `../`.
3. **`receitas/doces/pudim.html`**: dois `../`.
4. Abram as cinco páginas: o fundo e o `h1` são iguais em todas?
5. No `estilos.css`, mudem a cor do `h1` e vejam as cinco páginas mudarem.
6. Validem uma das páginas (validator.w3.org/nu) e o CSS (jigsaw.w3.org/css-validator).

O `link` vai no `head`, logo a seguir ao `title`:

```html
<link rel="stylesheet" href="css/estilos.css">
```

**Pronto quando:** uma mudança no `estilos.css` aparece nas cinco páginas, sem tocarem no HTML.

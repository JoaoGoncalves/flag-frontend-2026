# Exercício 11.1 · A folha de estilos do site das receitas

> Parte 11 · CSS: o que é e onde se escreve · sessão 7 (10 min)

Na página da horta (`exemplos/11-aplicar-css/`) aplicámos CSS de três formas. No site das receitas usamos a **externa**: um só ficheiro para as cinco páginas.

1. Em `s07/site/`, criem a pasta `css/` e, lá dentro, o ficheiro `estilos.css`.
2. Escrevam estas duas regras:

   ```css
   body {
     font-family: Georgia, "Times New Roman", serif;
     color: #2b2b2b;
     background-color: #fffaf0;
     line-height: 1.6;
   }

   h1 {
     color: #8a5a00;
   }
   ```

3. O `link` no `index.html` e no `sobre.html` (estão na raiz), no `head`, logo a seguir ao `title`:

   ```html
   <link rel="stylesheet" href="css/estilos.css">
   ```

4. No `receitas/bolo-de-bolacha.html` e no `receitas/posset-de-limao.html`: um `../`.
5. No `receitas/doces/pudim.html`: dois `../`.
6. Validem o CSS em jigsaw.w3.org/css-validator.

**Pronto quando:** as cinco páginas têm o mesmo fundo e o mesmo `h1`, e mudar uma cor no `estilos.css` muda o site todo.

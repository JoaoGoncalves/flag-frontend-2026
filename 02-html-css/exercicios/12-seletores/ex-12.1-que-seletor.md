# Exercício 12.1 · Que seletor?

> Parte 12 · Seletores · sessão 7 (no slide, 5 min)

Escrevam só o seletor (sem as chavetas) que escolhe:

1. Todos os `h2` da página
2. Só os links que estão dentro do `nav`
3. Os elementos com `class="nova"`
4. O elemento com `id="topo"`
5. Os `h1` e os `h2`, com a mesma regra
6. Um link quando o rato passa por cima

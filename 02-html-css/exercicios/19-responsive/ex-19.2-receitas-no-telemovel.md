# Exercício 19.2 · O site das receitas no telemóvel

> Parte 19 · Responsive · **para treinar, em casa** (sem entrega obrigatória)

No vosso site das receitas (a pasta `site/` mais recente: a da sessão 10, ou a vossa, se a foram melhorando), no fim do `css/estilos.css`.

1. **O viewport:** confirmem que **todas** as páginas têm `<meta name="viewport" content="width=device-width, initial-scale=1.0">` (as receitas também).
2. **As imagens e o vídeo flexíveis:** nunca mais largos do que o ecrã (`max-width: 100%` e `height: auto`).
3. **O menu, mobile-first:** no telemóvel, os links um por baixo do outro; **a partir de `40rem`**, numa linha (com flexbox e `gap`).
4. **A lista das receitas:** no telemóvel, a imagem em cima do texto; **a partir de `40rem`**, a imagem à esquerda e o texto à direita.
5. **As tabelas:** se uma tabela não couber no telemóvel, ponham-na dentro de uma `div` com `overflow-x: auto` (a tabela faz scroll; a página não).
6. **Testem** no DevTools (modo dispositivo) com um telemóvel pequeno (360px de largura) e **validem** o HTML e o CSS.

**Pronto quando:** no modo dispositivo, nenhuma página do site tem scroll para o lado e o menu muda de forma aos `40rem`.

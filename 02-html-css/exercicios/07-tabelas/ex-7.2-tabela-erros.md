# Exercício 7.2 · Encontrar os erros na tabela

> Parte 7 · Tabelas · **para treinar, sem entrega obrigatória**

Ficheiro: `ex-7.2-tabela-erros.html` (nesta pasta).

1. Abram o ficheiro no VS Code e no validador (https://validator.w3.org/nu).
2. Encontrem **5 problemas** (o validador dá 4 erros e 1 aviso) e **1 armadilha** (é válida, mas nós não a escrevemos assim).
3. Corrijam-nos, acrescentem `thead` e `tbody` e validem até dar "No errors".

A solução fica no GitHub em `solucoes/07-tabelas/`.

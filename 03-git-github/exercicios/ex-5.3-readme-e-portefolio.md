# Exercício 5.3 · Um README para as receitas (para casa)

**Sessão 3 do módulo 3 · para casa**

Um repositório sem README é uma pasta sem etiqueta. Vão dar às receitas a apresentação que um repositório a sério tem, e deixar o link no Moodle.

## O que fazer

1. No vosso repositório das receitas (no computador), criem o ficheiro **`README.md`** na raiz, em Markdown, com:
   - um título (`# As receitas da …`);
   - uma frase a dizer o que é o site;
   - o link do site no GitHub Pages;
   - uma lista com as receitas que lá estão;
   - uma secção *Como ver no computador* (abrir o `index.html` no browser);
   - *(opcional)* uma imagem do site: `![O site das receitas](img/…)`.
2. Juntem um `.gitignore` com `.DS_Store` e `Thumbs.db`, se ainda não o tiverem (do 4.3).
3. Commit (`docs: acrescenta o README`) e `git push`. Vejam no GitHub: o README aparece por baixo dos ficheiros.
4. Na página do repositório, na caixa **About** (a roda dentada à direita): uma descrição, o link do site (*Use your GitHub Pages website*) e dois ou três *topics* (`html`, `css`, `flag`).
5. Deixem o link do repositório e o do site no fórum do módulo 3, no Moodle.

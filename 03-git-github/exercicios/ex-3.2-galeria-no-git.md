# Exercício 3.2 · A galeria no Git (para casa, opcional)

Refaçam a galeria responsiva (o 19.1 do módulo 2), mas agora com o Git a guardar cada passo.

1. Numa pasta nova, `flag-frontend/03-git-github/s01/galeria`, copiem a galeria **sem a grelha**. Está no GitHub, em `02-html-css/exercicios/18-grid/ex-18.1-galeria/`.
2. Criem o repositório e façam o primeiro commit: "Galeria sem a grelha".
3. Escrevam a grelha do 18.1 e façam o commit.
4. Tornem-na responsiva passo a passo, com um commit por passo: o telemóvel (1 coluna), o tablet (2 colunas, a partir de 40rem) e o ecrã grande (6 colunas, a partir de 64rem).
5. Extra: o zoom das imagens e o título com `clamp()`, cada um no seu commit.
6. No fim, o `git log --oneline` deve contar a história da galeria, do primeiro ao último passo.

**Não fizeram o módulo 2?** Usem a galeria feita, que está no GitHub em `02-html-css/solucoes/19-responsive/sol-19.1-galeria-responsiva/`. Comecem pelo ponto de partida do passo 1 e, em cada passo, copiem da galeria feita só o bloco de CSS desse passo (a grelha, depois cada `@media`, depois cada extra), com um commit por passo. O exercício é o Git, não o CSS.

Na sessão 2 vamos usar uma galeria assim para experimentar os **branches**.
